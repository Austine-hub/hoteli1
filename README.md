## ✨ Features

* 🚀 **Modern Tech Stack** — React 18, TypeScript, Vite for blazing-fast builds
* 📱 **Fully Responsive** — Optimized for desktop, tablet & mobile
* 🎨 **Scoped Styling** — CSS Modules for maintainable component-based styles
* 🖼️ **Interactive Gallery** — Modal viewer with swipe & keyboard navigation
* 🧭 **Smart Navigation** — Sticky header, smooth scroll, mobile menu
* 🍽️ **Menu Showcase** — Dedicated sections for Lunch, Coffee, Wellness, Specials
* 📞 **Direct Booking** — One-click call-to-action buttons for reservations
* 🌍 **Authentic Kenyan Touch** — Design inspired by local hospitality culture
* ⚡ **Optimized Performance** — Fast load times, smooth transitions & animations

## 🚀 Quick Start

### Prerequisites

* **Node.js** ≥ 18
* **npm** ≥ 8 / **yarn** ≥ 1.22

### Installation

```bash
# Clone repo
git clone https://github.com/YOUR_USERNAME/hoteli1.git
cd hoteli1

# Install dependencies
npm install   # or yarn install
```

### Development

```bash
npm run dev
# visit http://localhost:5173
```

### Production

```bash
npm run build
npm run preview
```
